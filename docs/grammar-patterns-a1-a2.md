# Patrones gramaticales A1 / A2

Registro canónico en código: `lib/courses/grammar-patterns.ts`.

La columna **Orden** es la secuencia pedagógica. La ruta `/courses` sigue este orden en el bloque esencial (`lib/courses/level-curriculum-order.ts`).

> **Nota:** renumerar la ruta cambia URLs `/courses/study/:n?level=a1|a2`. El progreso se guarda por número de lección, no por slug.
