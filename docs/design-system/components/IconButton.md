Botón circular solo con icono, para escuchar audio o acciones de cabecera; siempre lleva `aria-label`.

- `ej-icon-btn--audio` (58px, tinta con icono sky): escuchar la palabra o frase principal de una tarjeta pastel. Uno por tarjeta, arriba a la derecha del título.
- `ej-icon-btn--audio-sm` (34px, tinta al 8%): escuchar un ejemplo dentro de un inset.
- `ej-icon-btn--neutral` (48px): cabecera sobre `bg` (notificaciones).

El consumidor aporta el icono (Lucide `volume-2`, `bell`) y el `aria-label` en español: “Escuchar frase”.
