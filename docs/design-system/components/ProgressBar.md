Barra de progreso en píldora de 14px con borde de tinta, pensada para tarjetas pastel.

- Por defecto: pista `lilac-deep`, relleno `ink`, borde 1.5px `ink`.
- `ej-progress--neutral`: sobre `bg` o `surface`; pista `surface-raised`, relleno `accent`.
- El consumidor aporta el porcentaje (`width` del relleno) y un texto visible (“0 de 740”) o `role="progressbar"` con `aria-valuenow`.
